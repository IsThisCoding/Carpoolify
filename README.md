# Carpoolify

## Overview
Carpoolify uses SvelteKit and a Postgres databse via Drizzle ORM to help users plan and optimize their own carpooling routes.
Originally started as a hackathon project ion highschool where my group failed miserably (I was the only one who knew javascrip). Later that year, I started a project in my CS class to rewrite it by myself, during which I learned a lot about typescript and some slightly more advanced programming topics. This is the most recent rewrite, with a wider and more ambitious scope, acting as a full on app with users. Currently, the backend is nearly complete (although some clearnup is necessary), and the frontend is heavily WIP, but things like authentication are working. Currently unfeasible to host as Vroom Express recquires an obscene amount of RAM to load OSM (open street map) files, and I am a broke college student with a Raspberry Pi and a dream.
